# Rock-Paper-Scissors-Game

Project Overview

This is a simple Rock-Paper-Scissors game built using vanilla JavaScript. The game allows users to play against the computer, where the computer’s move is generated randomly. The application tracks wins, losses, and ties using the browser’s localStorage, so the score persists even after refreshing the page. The project demonstrates core JavaScript concepts such as functions, event listeners, conditionals, DOM manipulation, and localStorage usage. I plan to continuously improve this project by adding UI enhancements, animations, and additional features.
